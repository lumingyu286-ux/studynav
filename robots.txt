# 主力站和镜像站都用这一份：允许抓取。
#
# 镜像站不要改成 Disallow: /
# 爬虫被 robots 挡住就不会去取 HTML，也就永远看不到 index.html 里的
# noindex，而该网址仍可能凭外部链接被只收录网址。要可靠地不被收录，
# 必须是「允许抓取 + 返回 noindex」这个组合。
#
# 镜像站该做的是：取消 index.html 里 noindex 那一行的注释。本文件不动。

User-agent: *
Allow: /


# 这里不加 Disallow: /README.md。
# 理由就是上面那几行：挡住抓取，爬虫就永远读不到 _headers 发的
# X-Robots-Tag: noindex，该网址反而可能凭外链被只收录网址。
# Cloudflare 那边靠 _headers 的 noindex 生效；GitHub Pages 不认
# _headers，README 在那边是可抓可收录的——仓库本来就是公开的，
# 真不想公开就别把 README 发上去。
